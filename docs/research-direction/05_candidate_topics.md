## 0. 已撤销选题

以下旧方向不再作为候选主线：

- ReliablePEFT：小验证集下的配置选择可靠性；
- LCB/Bootstrap/确认集等选择策略比较；
- AutoResearch champion 晋升或 `/selection-audit`；
- Agent vs BOHB 的一般性对比；
- “Agent + CleanLab + LoRA”的系统拼装；
- 仅把已有噪声学习方法扩展到另一种模态。

它们可以成为实验基础设施、基线或附属分析，但达不到当前成果门槛。

## 候选 A：未知混合数据缺陷下的计算预算分配

### 核心问题

当训练集同时可能包含错标、输入退化、分布外样本和重复低信息样本，且缺陷类型与比例未知时，如何在固定 GPU 小时内决定：

- 哪些样本值得继续训练；
- 哪些样本需要降权、软化标签或暂缓使用；
- 哪些样本虽然困难但包含有效信息，不能被误删；
- 何时停止在低价值样本上继续消耗计算。

### 可能的论文贡献

1. 一个面向未知混合数据缺陷、以 GPU 预算为约束的问题定义；
2. 一个基于训练动态的样本边际效用估计方法；
3. 一个效果—GPU 时间—显存联合评价协议；
4. 在视觉与真实噪声音频上的验证；只有机制需要时才加入文本。

### 最小否证实验

- 固定预训练骨干、PEFT 配置和数据划分；
- 在视觉数据中分别构造错标、输入退化、OOD 和混合缺陷；
- 与 CE、鲁棒损失、small-loss、CleanLab/筛样本和随机预算分配比较；
- 使用一个模型、固定训练步数和固定 wall-clock 两种公平口径；
- 若候选信号不能区分“困难干净样本”和“低价值坏样本”，立即否决。

### 最强拒稿理由

“这只是 sample reweighting、data valuation 和 curriculum learning 的组合，没有新理论，也没有独特算法。”

### 当前判断

潜力最高，风险也最高。必须先完成跨领域 novelty audit，不能直接实现。

## 候选 B：任务无关的训练价值估计

### 核心问题

能否从模型训练过程中产生的逐样本信号，估计一个不依赖具体模态结构的训练价值，使同一个判据在图像和音频上保持校准？

候选信号可能涉及 loss 轨迹、预测稳定性、遗忘事件或梯度一致性，但任何具体组合都必须相对现有工作证明差异。

### 可能的论文贡献

1. 对“样本可靠性”和“样本训练价值”作出可操作区分；
2. 提出跨任务校准而非每个数据集重新调阈值的估计器；
3. 证明估计误差与最终固定预算性能之间的关系；
4. 给出真实噪声音频的外部有效性证据。

### 最小否证实验

- 只使用两个小型分类任务；
- 在一个任务上拟合或设定规则，在另一个任务零调参迁移；
- 同时评估噪声检测质量和最终训练收益；
- 若必须针对每个数据集重新搜索阈值，撤销“任务无关”主张。

### 最强拒稿理由

“跨模态只是在两个数据集上复用同一套 loss statistics，不能证明通用性。”

### 当前判断

适合作为候选 A 的核心技术假设，不宜独立仓促立题。

## 候选 C：真实噪声音频作为关键验证场

### 核心问题

视觉噪声学习方法在真实网页音频错标、OOD 音频和低信噪比输入下是否仍有效？哪些失败来自标签错误，哪些来自输入不可辨识？

### 作用边界

- [FSDnoisy18k](https://zenodo.org/records/2529934) 提供真实噪声标签与人工核验数据，可作为高价值验证集；
- 音频不单独构成主线，因为音频噪声学习和 FSDnoisy18k 基线已经存在；
- 若最终方法涉及跨模态样本价值估计，音频是必要外部验证；
- 若最终方法只针对视觉结构，则不强行加入音频。

### 最强拒稿理由

“只是把已有视觉或文本方法移植到音频，适合领域会议实验论文，不足以达到 CCF-A/T1。”

### 当前判断

保留为验证场，不作为独立候选论文。

## 候选决策规则

候选 A/B 只有同时满足以下条件才可进入正式实验：

1. 最近工作不能通过直接换数据集或换 backbone 完成同一件事；
2. 最小实验出现预注册的机制信号；
3. 强简单基线无法达到相同效果；
4. 方法在固定 GPU 时间下仍有收益；
5. 能形成 CCF-A Full/Regular paper 或学校 T1 期刊所需的完整证据链；
6. 最强拒稿理由有正面、可验证的回答。

若没有候选通过门禁，应继续换问题，不以降低投稿级别解决问题。

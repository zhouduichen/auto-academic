# 04 — 研究缺口审计

> 状态：重新审计中
>
> 更新日期：2026-07-31
>
> 重要变更：撤销“PEFT 配置选择可靠性”为推荐主线。低质量训练数据与噪声鲁棒训练是当前问题域，但在完成最新相邻工作审计前，不把任何候选问题写成已确认空白。

---

## 1. 已确认的实际问题

用户在训练自己的模型时面临以下约束：

- 训练数据质量可能低于预期，包含错标、低质量输入、重复样本或分布外样本；
- 只有一张桌面端 RTX 5080，不能依赖多卡、大规模模型集成或无限次超参数搜索；
- 目标不是完成一个可演示的训练脚本，而是形成至少达到 **CCF-A 或学校正式认定 T1** 水平的研究成果。

因此，本项目的问题域是：

> **固定单卡计算预算下，如何让模型从未知质量、可能含多种缺陷的训练数据中学习到更多有效信号，并减少对错误或无效信息的记忆？**

“单卡”“PEFT”“图像/文本/音频”是约束或验证场景，不自动构成学术新颖性。

---

## 2. 不能再声称的研究空白

以下方向已有直接相邻工作，不能写成“首次研究”：

| 已覆盖方向 | 直接证据 | 对本项目的约束 |
|---|---|---|
| 噪声标签下的鲁棒 PEFT | [CleaR, ACL 2024](https://aclanthology.org/2024.acl-long.322/) 已研究 PEFT 容量、噪声干扰与 clean routing | 不能只做“噪声下的 LoRA/Adapter 路由” |
| 双 LoRA 检测噪声标签 | [Delora, ACL Findings 2025](https://aclanthology.org/2025.findings-acl.792/) 已将 clean/noisy LoRA 用于检测和训练 | 不能把双适配器或小损失筛样本当作核心新意 |
| LoRA 秩与噪声记忆 | [RACT, 2026 预印本](https://arxiv.org/abs/2602.00084) 已给出容量、最优秩与时间分离分析 | 不能只研究 rank × noise，或据此做简单课程训练 |
| 通用鲁棒损失 | [Normalized Losses, ICML 2020](https://proceedings.mlr.press/v119/ma20c.html) 等已提供强基线 | 换一个 loss 或组合已有 loss 不足以支撑目标级别 |
| 预训练模型的噪声鲁棒微调 | [IJCAI 2024](https://www.ijcai.org/proceedings/2024/403) 已研究线性头、数据降噪与微调 | 不能只把“先筛样本再微调”改名 |
| 真实噪声音频分类 | [FSDnoisy18k](https://zenodo.org/records/2529934) 及其基线已覆盖真实网页音频错标 | 音频数据集可作验证，但数据集本身不是新贡献 |

同样撤销以下旧主张：

- “没有工作研究 PEFT 选择是否可靠”；
- “增加 `/selection-audit` 就是论文贡献”；
- “把 AutoResearch 或 ARIS 接入训练流程就是研究创新”；
- “跨图像、文本、音频验证即可证明方法通用”。

## 3. 待审计的候选研究缺口

这些是需要检索和最小实验共同验证的候选问题，不是已成立结论。

### G1：未知混合数据缺陷下的预算约束学习

现有工作通常单独假设已知的对称错标、类别相关错标或某一种真实噪声。真实训练集可能同时包含：

- 标签错误；
- 低信噪比、模糊、截断或压缩等输入退化；
- 与目标类别无关的分布外样本；
- 重复、近重复和低信息样本；
- 类别不平衡与噪声耦合。

候选问题是：在缺陷类型和比例未知时，能否在固定 GPU 小时内估计样本的训练价值，并分配有限训练计算？

**新颖性风险：** 与 data valuation、curriculum learning、coreset selection、robust learning 和 data-cleaning AutoML 高度交叉。必须证明现有方法在“未知混合缺陷 + 固定计算预算 + PEFT”交叉条件下确有结构性不足。

### G2：跨模态可迁移的样本价值信号

候选问题是：是否存在只依赖逐样本训练动态、而不依赖图像/文本/音频特定结构的可靠性或边际效用信号？

**新颖性风险：** loss dynamics、confidence、forgetting events、gradient alignment 和 influence estimation 均已有大量工作。必须提出新的可检验机制，而不是重新加权已有指标。

### G3：准确率与计算成本联合最优的鲁棒微调

许多噪声学习方法使用双网络、多阶段重训练、交叉验证或外部大模型重标注。候选问题是：在同一 GPU 时间、显存和训练数据访问次数下，现有排行榜是否发生变化，以及能否设计严格优于强基线的单模型方法？

**新颖性风险：** “更便宜”本身不够。必须同时证明性能、效率和机制收益，并避免通过减少训练量制造不公平对比。

## 4. A/T1 级研究门禁

候选问题只有同时通过以下门禁，才允许进入正式大实验。

### N1：新颖性门禁

- 完整精读 CleaR、Delora、RACT、IJCAI 2024 robust fine-tuning；
- 检索 2024—2026 年 noisy-label learning、data valuation、sample selection、curriculum learning 和 compute-aware training；
- 为每个候选机制写出“最近工作为什么不能直接完成它”；
- 若差异仅是换模态、换骨干或增加一个权重项，立即否决。

### N2：机制门禁

- 提出能够被最小实验推翻的机制假设；
- 观察量必须来自训练过程，不得使用测试集调参；
- 至少存在一个结果模式能够说明假设错误，而不是任何结果都能事后解释。

### N3：方法门禁

- 方法不能是已有模块的线性拼装；
- 相对强基线必须有清晰的结构差异；
- 单卡可执行，但不能以牺牲公平性换取“低成本”；
- 同时报告效果、GPU 时间、峰值显存和额外存储。

### N4：证据门禁

- 至少包含合成可控缺陷与真实低质量数据；
- 至少两个实质不同的任务或模态；第三模态只在需要证明通用性时加入；
- 数据划分、训练随机性和噪声生成使用独立种子；
- 预注册主要指标、主比较、停止条件和失败条件；
- 最终只针对 CCF-A Full/Regular paper 或学校正式 T1 目录规划。

---

## 5. 最强拒稿理由

在进入实验前，默认以下意见来自最强审稿人：

1. **问题不新**：这只是 noisy-label learning 在 LoRA 上的复现。
2. **方法不新**：样本降权、伪标签、课程学习和动态路由都已有。
3. **跨模态是假通用**：相同代码在三个分类数据集运行，不等于机制具有通用性。
4. **低算力不是贡献**：一张 GPU 是作者资源限制，不是科学问题。
5. **实验规模不足**：单数据集、三种子和人工对称噪声不足以支撑顶级结论。
6. **效率比较不公平**：不同方法没有在相同 wall-clock、数据访问次数或调参预算下比较。
7. **真实噪声缺失**：只使用人工翻转标签，无法代表现实低质量数据。

任何候选题目必须逐条给出实验或理论回答。

---

## 6. 当前结论

- 旧的 ReliablePEFT/选择可靠性主线已撤销。
- 噪声鲁棒 PEFT 是问题域，但已有工作密集，不能直接定题。
- 当前最值得审计的是“未知混合数据缺陷下的计算预算分配”，不是某个预设 loss 或 LoRA 变体。
- 音频是有价值的真实噪声验证场；是否加入文本由最终机制决定。
- 在完成 N1 新颖性门禁前，不启动大规模 Phase 2，不撰写论文题目和贡献声明。

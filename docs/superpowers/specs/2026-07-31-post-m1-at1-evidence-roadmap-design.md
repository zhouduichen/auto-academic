# M1 后 A/T1 证据路线与并行文献轨设计

> 日期：2026-07-31  
> 计算边界：文献、代码/许可证审计、统计设计、理论准备和论文工作只在 Mac 本机完成；只有训练、批量推理或其他经验证实需要高性能的计算才提交 Windows RTX 5080  
> 定位：条件式参考路线，不授权 M1 之后的 GPU 实验  
> 成果门槛：CCF-A Full/Regular 或学校正式认定 T1

## 1. 设计目标

M1 本身已是冻结方法后的确认阶段。M1 之后不应继续重复证明“在
CIFAR-100/ViT-LoRA/40% instance-dependent noise 上有效”，而应通过最小、
正交的证据逐层扩展可以写入论文的主张。

本设计将旧的线性 `F1 → F2 → F3` 试验清单改为：

1. M1 结果分支；
2. 主张—证据图；
3. 主张、方法和数据门三重冻结；
4. 机制、现实有效性、失败边界和理论四条证据轨；
5. 与 GPU 实验并行、现在即可开始的本地文献与审计轨。

## 2. M1 结果分支

### 2.1 `NO-GO`

停止 optimizer-admission 算法线，不铺新数据集、不降低投稿目标、不寻找更有利的噪声条件。
保留 M0.6 的污染机制证据，完成负面结果归档、失败机制分解和反重复研究记忆，
然后返回新问题的文献与创意门。

### 2.2 `INCONCLUSIVE`

不得解释为“接近成功”。只使用现有日志完成 paired-effect、seed/noise/augmentation、
admission 行为和基础设施故障分解。不追加同一数据门的 seeds。若发现可修正的机制缺陷，
必须建立新算法版本、新设计和未使用的数据门；否则停止。

### 2.3 `GO`

M1 只支持以下有限主张：

> 在冻结的 CIFAR-100、ViT-LoRA 和 40% instance-dependent label noise 条件下，
> 候选相对最强简单基线获得预注册收益，同时满足干净非劣与效率约束。

它不支持“真实噪声有效”、“普遍适用于视觉”、“模态无关”或宽泛理论优越性。

## 3. 主张—证据图

| 主张 | 问题 | 主要证据 |
|---|---|---|
| C0 污染存在 | 异常梯度是否持续污染优化器状态 | M0.6 |
| C1 方法有效 | 控制持久写入是否提高受噪训练性能 | M1 |
| C2 因果归因 | 收益是否来自即时/持久通路解耦 | 机制消融与反事实状态注入 |
| C3 真实噪声 | 合成噪声收益能否迁移到真实标签错误 | 真实噪声视觉数据 |
| C4 结构/规模迁移 | 收益是否不限于一个 ViT-LoRA 设置 | 新骨干、规模压力和 full-FT 边界 |
| C5 安全边界 | 是否伤害困难干净样本、少数类或系统性偏置 | 边界与负对照实验 |
| C6 理论解释 | 污染传播及抑制能否被形式化 | 定理、反例、数值验证和代码映射 |
| C7 跨模态 | 无需改机制是否可迁移 | 可选的真实噪声音频验证 |

A/T1 最低证据需要 `C0 + C1 + C2 + C3 + C5`，并在 `C4` 和 `C6` 中至少有一项强证据。
`C7` 默认不启动，只有主张确实包含跨任务或跨模态迁移时才进入。

## 4. 三重冻结

### 4.1 主张冻结

M1 后、任何新 GPU 实验前，更新最近六个月查新，冻结 3–5 条技术主张、
每条主张的主要终点、支持证据、撤销条件和最强拒稿理由。

### 4.2 方法冻结

M1 候选的机制、非标准参数和默认规则冻结。后续修改必须提升版本；旧结果不得与新版本合并，
新版本重新通过最小效果门。

### 4.3 数据门冻结

每个正式数据集分离 tuning、development 和 final evaluation。方法、参数、主要比较和
分析代码冻结后，测试数据只打开一次。

## 5. M1 后任务矩阵

### R0：M1 结果封存

- 时间：1–3 天，无 GPU。
- 工作：验证配置、随机性、数据访问、失败/重试和文件哈希；独立重算统计量；封存原始预测、轨迹和 checkpoint。
- 产物：`CLAIM_LEDGER.yaml`、`EVIDENCE_MAP.md`、`EXPERIMENT_AUDIT.json`、`M1_DECISION.json` 和哈希清单。

### R1：最后文献与主张冻结

- 时间：因前置文献轨压缩为 M1 后 1–2 天，无 GPU。
- 工作：增量检索、精确 recurrence 重叠、最强简单/直接基线冻结、主张撤销规则。

### R2：机制闭环

- 预计新增 20–24 个完整训练运行和一批短轨迹实验。
- 预计算力：3–6 GPU 天。
- 主消融：完整候选、关闭 persistent-state admission、rate-matched 随机 admission。
- 次消融：去历史一致性、阻断即时通路、M/MV 结构、固定阈值。
- 硬停止：随机 admission 与完整方法等价；收益来自取消困难样本的即时更新；实现与机制描述不符。

### R3：小规模真实噪声复制

- 预计算力：1–2 GPU 周。
- 方法：AdamW、M1 最强简单基线、冻结候选、最近直接噪声方法。
- 重复：主要比较 5 个配对 seeds。
- 硬停止：真实噪声上无实际收益；被直接方法在准确率、时间和显存上同时支配；少数类/困难干净样本超过安全退化界。

### R4：规模和结构迁移

- 预计算力：3–6 GPU 周。
- 单元：一个较大真实网络噪声基准、一个实质不同的 CNN/ConvNet、一个 full-finetune 边界。
- 不做数据集×骨干×方法的完整笛卡尔积。
- 候选非标准参数不重新搜索，只允许公共训练参数的等预算校准。

### R5：失败边界和安全性

- 预计算力：1–2 GPU 周。
- 主边界：持续一致的系统性错误梯度、长尾/少数类、困难但标签正确的样本。
- 次边界：open-set、输入退化、batch 噪声比例突变、β/momentum 区间。
- 硬停止：收益仅来自忽略困难样本；系统性错误被稳定接纳且不可检测；需要已知噪声率才能安全使用。

### R6：音频外部验证（可选）

- 预计算力：1–3 GPU 周。
- 启动前提：R2–R5 通过；主张包含跨任务/模态迁移；算法机制和非标准参数不修改。
- 音频失败只撤销跨模态主张，不自动否定已完整的视觉主张。

### R7：理论、证据统一和论文审计

- 理论在 R1 后与 R2–R5 并行。
- 对象：异常梯度的一阶矩传播、累计参数污染、admission recurrence 上界、误接纳/误拒绝项、系统性偏置反例。
- 每个理论对象必须映射到实际代码状态和数值实验。

## 6. 现在开始的并行本地文献轨

### L0：稳定前置工作（立即开始）

L0 不依赖 M0.6/M1 结果，只在 Mac 本机执行：

1. 定向补全 optimizer-state contamination、selective moment update、robust Adam/momentum、
   gradient agreement/temporal consistency、noisy-label PEFT 和单模型低开销直接方法。
2. 审计 DSS、ELR、PNM/AdaPNM、clipping 等基线的官方来源、license、commit、算力路径和 ViT-LoRA 兼容性。
3. 审计预排序正式数据集的官方来源、license、split、真实噪声来源、评价脚本和单卡预算。
4. 准备 AdamW 矩递推、bounded/biased contamination 假设、系统性一致错误反例和理论—代码映射模板。
5. 冻结 paired 分析、非劣界、固定 steps/wall-clock、层级多重比较、功效分析和证据文件模板。

当前起点是 40 篇已验证候选记录和 12 篇直接先验深读矩阵。L0 的主要缺口是
optimizer-state 定向补全，以及将现有矩阵中的 `candidate_not_generated` 更新为对冻结候选
recurrence 的逐项比较。

### L1：候选机制冻结后、M1 开跑前

将候选拆成 3–5 条精确技术主张；每条使用至少三组检索式，检索最近六个月，进行公式级重叠、
官方代码和最强等价实现反证。若已有方法能等价实现核心 recurrence，在 M1 大规模投入前停止。

### L2：M1 运行期间的每周增量检索

只检索上次截止日之后的新工作，维护 killer-prior watchlist。新文献不得修改正在运行的确认协议；
经原文、代码和元数据验证的完全等价工作可以停止尚未开始的后续 GPU 队列。

### L3：M1 完成后的最终刷新

仅搜索 L2 截止日之后的新工作，将 M1 实际支持的结果映射到主张，删除不受支持的贡献，
并冻结最终 claim-by-claim matrix。因 L0–L2 前置，此阶段应压缩到 1–2 天。

## 7. ARIS 角色与强制约束

ARIS 用于文献发现、查新、完整性、结果—主张、引用和最强拒稿理由审计，不是论文贡献。

约束：

- 本地 ARIS `experiment-audit` 默认是 advisory，即使 `FAIL` 也不自动阻断；本项目的确定性哈希、数据门、配对、有限值和预注册校验是绑定门。
- 当前 `result-to-claim` 和 `auto-review-loop` 执行模块未激活，路线不依赖它们自动完成科学判定。
- 同族 Codex reviewer 结论只标记 `provisional`，不等于跨模型或人类审评通过。
- 正式确认协议冻结后，ARIS reviewer 提出的新实验只能被分为已预注册、明确标记的探索性实验，或使用新数据门的新版预注册实验。
- `kill-argument` 只在标题/摘要稳定、实验完成后使用；不用于早期边做边补。
- `paper-claim-audit` 只读论文源文件和原始结果，不读执行者摘要；所有量化主张必须可追溯。

## 10. 总停止规则

任一条成立即停止主线或撤销对应主张：

- 最近工作可等价实现核心 recurrence；
- M1 为 `NO-GO`，或 `INCONCLUSIVE` 且无可验证的新机制版本；
- 机制消融表明收益不来自持久状态控制；
- 真实噪声无实际收益或直接方法严格支配候选；
- 收益需要额外模型、阶段、前后向、干净参考或已知噪声率；
- 方法明显伤害少数类或困难干净样本；
- 理论对象与实际代码无法对应；
- 完整证据仍只能支撑低于 A/T1 的应用级结论。

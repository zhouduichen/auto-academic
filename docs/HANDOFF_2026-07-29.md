### 4.2 合并前必须修复的 3 个 blocker

1. **Installer HOME symlink escape**  
   managed-path guard 未覆盖 `.aris/installer-home` 及全部实际管理子路径。预置 `installer-home` symlink 可把官方 installer 的 `HOME` 指向 workspace 外。必须显式区分受管目录/文件，逐层拒绝 symlink 和错误类型，并增加越界红测。

2. **Rollback failure 被吞掉**  
   `_rollback_install` 当前吞掉官方 uninstall 失败。若 post-install preflight 失败且 rollback 也失败，必须聚合两个错误、保留 manifest/links/rules 供诊断，不能清理状态后让调用者误以为已回滚。

3. **真实 gate 未固化**  
   增加 `tools/stage_a2_gate.py`（或同等入口）：在临时 workspace 使用固定 ARIS clone 跑真实 plan → install → preflight → uninstall，核对 82 entries、13 个 blocked target 和零残留；同时让真实 Codex execpolicy 解析 deny rules 并验证 `ssh` 为 forbidden。默认 `make quality` 保持离线，可用 `ARW_RUN_STAGE_A2_INTEGRATION=1` 显式启用 marked integration test。

推荐修复设计已经过初步讨论，但尚未写入代码：

- guard 覆盖 `.aris/vendor/{aris,aris-activation}`、`.aris/installer-home/.aris`、installer lock/manifest/prev/declined、wrapper state/tmp、`.agents/skills`、`.codex/rules`。
- rollback 成功才清 wrapper state/rules；rollback 失败时保留现场并抛包含原错误和 rollback 错误的 `ArisActivationError`。
